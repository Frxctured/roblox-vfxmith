# Library hero meshes cap quality

> TL;DR
> - All three plugin builds in T5 used library crystal meshes; reviewers called them smooth cones, a pincushion, glowing horns.
> - The baseline built its own faceted crystals and won.
> - A library mesh can only be tinted as a whole, so it reads as one flat colour.
> - The library helped when the builder read the category study for techniques, not when it copied shapes.

## Takeaway
Use pro work for composition, techniques and values; design or source hero shapes for the effect itself. In v1 the
builder starts from a pro composition the owner rated well, not from the nearest library mesh.
