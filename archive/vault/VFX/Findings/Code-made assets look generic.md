# Code-made assets look generic

> TL;DR
> - Assets drawn in code by Claude look too generic: a slash is a plain arc, smoke is a circle fading from the centre.
> - Hero art painted in code read as clip art next to a human-made reference (golden sigil).
> - Plain stretched ovals made a fire tornado look 'made of REALLY basic parts'.
> - v1 uses human-made textures first and generates only where they leave gaps, from real simulations (Blender fluid) or layered strokes, gated by owner ratings.

## Why
Organic material has structure at many scales (curls, wisps, uneven edges) that simple gradients and noise lack. Pro
textures are hand-painted or rendered from simulations.

## What the reference reels do instead (2026-11-18)
The owner's quality-bar reels show what "not generic" means concretely: big shapes are hard-edged 2-tone cel shapes with
asymmetric silhouettes (3-4 spikes of different length, jagged erosion, spiky scorch), softness is a separate glow layer,
and fine detail comes from many tiny hard accents (4-point stars, dashes, dotted rings). See
[[Hard cel shapes, softness only in the glow layer]].
