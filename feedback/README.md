# Feedback: what people said about real effects

One file per effect, written after the person who asked for it watched it (the `vfx-feedback` skill asks the
questions and saves the answers). The answers stay in the person's own words. Each file ends with the general lessons
taken from it, and those lessons are merged into `knowledge/taste.md`, which every builder and reviewer reads.

Why: blind AI reviewers judge layout and timing well but miss what people notice first (too much glow, cheap
stretched sprites, a mark that vanishes too early). Human answers are the scale the plugin learns from, so every
effect made and rated makes the next one better, for everyone who updates the plugin.

File name: `YYYY-MM-DD-<effect-slug>.md`. Frontmatter: effect, request, made_with (plugin version or "no plugin"),
rating (1-10), cost_usd (if known), rater ("owner" for the plugin's maintainer, "user" otherwise).
