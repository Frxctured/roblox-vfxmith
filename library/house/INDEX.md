# House examples: effects people rated 8 or higher

Each folder has `effect.luau` (self-contained: run it once in Edit mode, then `_G.BlindTestPlay(origin, freezeAt?)` /
`_G.BlindTestStop()`), `frames.jpg` (frozen at the same times in daylight) and `note.md` (rating, the person's words,
what makes it work beat by beat, caveats). Learn the techniques; design your own effect. Add one with `vfx-feedback`.

|---|---|---|---|
